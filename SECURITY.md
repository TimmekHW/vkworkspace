# Security policy / Политика безопасности

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub: the repository's **Security** tab → **Report a vulnerability**
(<https://github.com/TimmekHW/vkworkspace/security/advisories/new>). Describe what is affected,
how to reproduce it, and the version of `vkworkspace` you use.

You can also write to the author directly: Telegram [@timmek1](https://t.me/timmek1).

Never include a real bot token, password or internal host name in a report — replace them with
placeholders.

## Supported versions

Security fixes are released for the latest `2.x` version.

## Как сообщить об уязвимости

Пожалуйста, **не** заводите публичный issue о проблеме безопасности.

Сообщите приватно через GitHub: вкладка **Security** репозитория → **Report a vulnerability**
(<https://github.com/TimmekHW/vkworkspace/security/advisories/new>). Опишите, что затронуто,
как воспроизвести и какая версия `vkworkspace` у вас установлена.

Можно написать автору напрямую: Telegram [@timmek1](https://t.me/timmek1).

Не вставляйте в сообщение настоящие токены ботов, пароли и внутренние адреса — замените их
заглушками.

## Поддерживаемые версии

Исправления безопасности выходят для последней версии `2.x`.
